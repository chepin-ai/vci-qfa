## A) 最深映射：共性 4「刚性等号即分类」→ 贵线机制级对应

### 为什么不是共性 1/2/3/5

- 共性 1「耦合为本」是**舞台设定**，不是机制。
- 共性 2「松弛生结构」是**方法**，但松弛方式各线不同，机制级对应会退化成比喻。
- 共性 3「最小假设最大正则」是**存在性/唯一性引擎**，重要，但它给出的是「有解且唯一」。
- 共性 5「尺度爆破」是**局部模型**，是推论层。
- **共性 4 才是判决层**：它告诉你「什么时候两个对象必须被视为同一类」。这正是联邦映射里「级名不滥」的机制内核。

### 机制级对应（逐项非比喻）

| 贵线机制 | 共性 4 的机制对应 | 判定谓词 |
|---|---|---|
| **fail-closed** | 凸性/下半连续性假设 = OT 中的 c-cyclical monotonicity 前提 | 若前提不满足 → 拒绝出解，而非给近似 |
| **ask 自包含** | 熵惩罚 → 唯一最优耦合的 strict convexity | 若问题无唯一极小 → ask 不合法（不可自包含） |
| **fp 互锚** | 距离 0 ⟺ 弱同构 | 两个 fp 锚定同一对象的判据是 **W₂=0**（或对应 OT 距离=0），不是「看起来一样」 |
| **公域 CI 通道** | 等距函子（关联图=等距） | CI 通过 ⟺ 映射保 OT 距离 |
| **级名不滥** | 单调量取常数 ⟺ 锥+齐次 | 级名稳定 ⟺ 单调量在等价类上取常值 |

### 关键机制级同构（这条是核心）

OT 里最硬的刚性等号是：

\[
\text{单调性公式取等} \iff \text{爆破极限是锥且齐次}
\]

把它翻译到贵线：

\[
\text{某个单调量（如 fail-closed 拒绝率、ask 自包含度、fp 互锚距离）在等价类上取常值}
\iff
\text{该类可被赋予稳定级名，且变换由等号条件唯一反推}
\]

**这就是「变换涌现而非假设」的机制级实现**：你不预设「什么算同一级」，你预设一个单调量，然后让**等号集**定义级。等号集是刚性的是因为 OT 的等号条件是刚性的（锥 + 齐次，无连续形变自由度）。

### 与元共性的闭环

- 元共性：变换涌现而非假设。
- 机制：单调量等号 → 等价类 → 变换（从等号条件解出）。
- 这正是 Collins–Tong 里「凸性 alone 即充分」的机制：**不需要额外假设变换，凸性 + 等号条件就把变换逼出来了**。

所以最深映射 = **共性 4，落到「级名不滥 + fp 互锚」这两个贵线机制上**，判定谓词是「单调量等号 / OT 距离=0」。

## B) 可操作可判定的「耦合/统一」实验

设计原则：对象要小到能跑，代价泛函要凸到能保证唯一性，判定谓词要二值，预期刚性等号要能被证伪。

### 实验名：**UNIFY-OT-MINI-01**

#### 对象

取三个**同一底层离散结构的不同表示**，构造三边缘 OT：

- \(X_1\)：原始图 \(G\)（邻接矩阵）
- \(X_2\)：\(G\) 的关联图 / 线图 \(L(G)\)
- \(X_3\)：\(G\) 上赋测度后的超图表示 \(H(G)\)

三者的**边缘测度固定为同一分布 \(\mu\)**（例如均匀分布在顶点/边/超边上，按各自基数归一化）。

#### 代价泛函

\[
C(\pi) = \int c\, d\pi + \varepsilon \int \pi \log \pi
\]

其中：

- \(c\) = 底层图上的最短路径距离（或超图上的 co-OT 距离）
- \(\varepsilon > 0\) = 熵惩罚系数
- \(\pi\) 是 \(X_i \times X_j\) 上的耦合

这是标准的**熵正则 OT**，严格凸 → 唯一最优耦合 \(\pi^*_{\varepsilon}\)。

#### 判定谓词

定义三个二值谓词：

1. **等距谓词** \(P_1\)：  
   \[
   W_2(\mu_i, \mu_j) = 0 \quad ?
   \]
   若 \(X_1, X_2, X_3\) 在 OT 距离下等距 → \(P_1 = \top\)。

2. **等号谓词** \(P_2\)：  
   单调量 \(M(\pi^*)\)（例如耦合的支撑集大小 / 传输计划的秩）在三个表示上取常值？  
   \[
   M(\pi^*_{12}) = M(\pi^*_{23}) = M(\pi^*_{13}) \quad ?
   \]

3. **函子谓词** \(P_3\)：  
   图化映射 \(G \to L(G) \to H(G)\) 是 Lipschitz 函子？  
   即存在常数 \(K\) 使  
   \[
   W_2(L(G), L(G')) \le K \cdot W_2(G, G')
   \]
   对扰动对 \((G, G')\) 成立。

#### 预期刚性等号

**主预测**：当 \(\varepsilon \to 0^+\) 时，

\[
P_1 = \top \iff P_2 = \top
\]

即：**OT 距离为 0 当且仅当单调量取常值**。这是共性 4 的直接体现：距离 0 ⟺ 弱同构，单调量等号 ⟺ 锥 + 齐次。

**次预测**：若 \(P_3 = \top\) 且 \(K = 1\)，则三表示在 OT 下**等距**，此时 \(P_1 = \top\)，级名可统一为同一级。

**证伪条件**：若存在 \(\varepsilon\) 使 \(P_1 = \top\) 但 \(P_2 = \bot\)，则共性 4 在该线上**不成立**，联邦映射需降级为「仅共性 3 成立」。

#### 可操作性

- 规模：\(|V| \le 20\)，\(|E| \le 40\)，可用 Sinkhorn 迭代在秒级求解。
- 代码：`POT`（Python Optimal Transport）或 `geomloss` 直接实现熵正则 OT。
- 判定：所有谓词都是二值，可用阈值 + 数值稳定性检查。
- 刚性：\(\varepsilon \to 0\) 的极限行为可通过对数尺度扫描 \(\varepsilon \in \{10^{-1}, 10^{-2}, 10^{-3}, 10^{-4}\}\) 观察 \(P_1, P_2\) 是否同步翻转。

#### 与联邦映射的接口

- **11 线 = 边缘测度**：三表示的 \(\mu_i\) 固定。
- **协议层 = 耦合空间**：\(\pi\) 的空间。
- **fail-closed = 凸性假设**：\(\varepsilon > 0\) 保证严格凸，若 \(\varepsilon = 0\) 且 \(c\) 非严格凸 → 拒绝判定。
- **公域 CI 通道 = 等距函子**：\(P_3\) 是 CI 通过条件。
- **级名不滥 = 单调量等号刚性**：\(P_2\)。
- **ask 自包含 = 熵惩罚唯一性**：\(\pi^*_\varepsilon\) 唯一。
- **fp 互锚 = 距离 0 弱同构**：\(P_1\)。

## 一句话总结

- **A**：最深是 **共性 4「刚性等号即分类」**，机制级落在「级名不滥 + fp 互锚」，判定谓词是「单调量等号 / OT 距离=0」，它是「变换涌现而非假设」的判决层实现。
- **B**：实验 **UNIFY-OT-MINI-01**，三表示 + 熵正则 OT + 三谓词 \(P_1, P_2, P_3\)，主预测 \(P_1 \iff P_2\)，证伪条件明确，规模可跑，接口与联邦映射一一对应。
