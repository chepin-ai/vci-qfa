## 定理陈述

d=4 两输入猜数游戏（EA-RAC-4）：Alice 收 x=(X₁,X₂)∈ℤ₄² 发 m∈ℤ₄；Bob 收 y∈{0,1} 猜 X_y。记量子值为 ω_q。则

**ω_q ≤ 0.7537703608**（认证上界，本证明）。

结合 beat-127/128 已认证的量子下界 3/4（uniform-win 构造 + T-谱），得认证区间

**ω_q ∈ [0.75, 0.7537703608]**

相对 beat-129 的 L1 认证上界 0.7803301383，区间宽度收窄 5.3×。

另（诚实声明，非认证断言）：1+AB 层 SDP 数值解原-对偶均收敛到 0.750000±5e-6（primal 0.74999987 / dualobj 0.75001），即层级在 1+AB 数值上恰好塌缩到下界 3/4；该"恰等于 3/4"为数值证据，不作为认证结论——认证结论以 0.7537703608 为准（迭诫七：数值平台 ≠ 上界，唯对偶见证证书认证）。

## 方法：对称扭曲的 commuting-operator NPA

1. **群结构**：游戏在 T×S = ℤ₄²×ℤ₄（64 阶阿贝尔群）下不变。t₁: X₁→X₁+1 且 Bob 在 y=0 时 v→v+1；t₂: X₂→X₂+1 且 Bob 在 y=1 时 v→v+1；s: m→m+1（双方同步）。对 NPA Gram 矩阵作群平均（twirl），矩阵按 64 个特征标分块；每对共轭特征标只留一块（PSD ⟺ 共轭块 PSD，是合法松弛：quantum ≤ NPA = twirled-full ≤ twirled-kept ≤ cert）。
2. **块结构（RAC4-1AB）**：词集 = I + 64 Alice 字母 + 32 Bob 字母 + 32×64 AB 对 = 2145 词。矩量按 (NF-类 ∪ G-轨道) 等价类聚合成 z 变量：1 个 I 轨道（稳定子 64）+ 1 个 Alice 自由轨道 + 2 个 Bob 轨道（稳定子 4）+ 32 个 AB 自由轨道 = 36 轨道；36 个块，块尺寸多重集 [36]+[35]×2+[34]×14+[33]×19（块 (p,q,r) 尺寸 = 33+[q==0]+[p==0]+[χ==0]）。z 变量总数 28439（含钉住的 zI=1）。
3. **块公式**：M_χ[O,O'] = (1/√(s_O s_O′)) Σ_k χ̄(k) z(class(w_O, k·w_O′))，其中 s_O 为轨道稳定子阶，w_O 为轨道代表词。
4. **F0 的正确理解**：F0_ρ ≠ I。钉住的 zI=1 只覆盖空词矩 Γ[(),()]=1；Γ[P,P]=⟨P⟩ 是真变量（正规形 P²=P 坍缩为单字母而非恒等）。不变量为 **Σ_ρ tr F0_ρ = 1**（F0 仅在平凡特征标块的恒等轨道上为 E₀₀）。已由 verify 第 3 项核验 Σtr=1.000000。
5. **求解器**：超松弛 ADMM（μ=0.2，α=1.6，α 打破平台）+ 合并实算子 St=[Re S; Im S] 的 CG 内解（对角预条件、热启动）+ 后半程遍历 Ȳ 平均 + LSQR 最小范数修正 / PSD 投影修复交替抛光（收缩率 q≈0.95–0.98）。总迭代 ~20.6k。
6. **证书公式（可审计、与迭代无关，对任意 Hermitian Y 有效）**：
   max cᵀz ≤ dualobj + pen + ‖r‖₁，
   dualobj = Σ_ρ Re tr(F0_ρ† Y_ρ)；pen = Σ_ρ max(0,−λmin(Y_ρ))·U_ρ；
   r = cv + Σ_ρ Re(S_ρ† vec(Y_ρ))（符号约定与 ADMM 鞍点 ΣSᵀY=−cv 一致）；
   U_ρ = Σ_diag|coef| + |tr F0_ρ|（用 |z_c|≤1）。
   证书对 Y 线性且凸，故轮次平均单调改善。
