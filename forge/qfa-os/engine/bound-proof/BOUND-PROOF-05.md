## §1 模型与 Schmidt 压缩归约（定理1，全证）

**模型**（2→1 EA-RAC，经典消息轴）：x=(x₀,x₁)∈{0,1}² 均匀，y∈{0,1} 均匀；Alice 与 Bob 共享 Schmidt 形 |ψ⟩=Σᵢ λᵢ|ii⟩（Schmidt 秩 r，Σλᵢ²=1）；Alice 按其输入 x 施 POVM {E_x^m}_{m∈{0,1}} 得消息 m 并经典发送；Bob 由 (m,y) 施 POVM {M^{m,y}_v}_{v∈{0,1}} 输出猜测。成功概率

S = (1/8) Σ_{x,y,m} tr[(E_x^m ⊗ M^{m,y}_{x_y}) |ψ⟩⟨ψ|]。

**定理1（Schmidt 压缩归约）**：令 D=diag(λ₀,…,λ_{r−1})。则

tr[(E ⊗ M)|ψ⟩⟨ψ|] = tr[D E^T D · M]，

且算符族 F_x^m := D (E_x^m)^T D 满足：F_x^m ≥ 0；Σ_m F_x^m = D² =: ρ_B（与 x 无关）；tr ρ_B = 1。

**证**：|ψ⟩⟨ψ| = Σᵢⱼ λᵢλⱼ |i⟩⟨j|⊗|i⟩⟨j|，故 tr[(E⊗M)|ψ⟩⟨ψ|] = Σᵢⱼ λᵢλⱼ E_{ji} M_{ji}。右式 tr[D E^T D · M] = Σᵢⱼ [D E^T D]_{ij} M_{ji} = Σᵢⱼ λᵢ E_{ji} λⱼ M_{ji}，逐项相等。完备性：Σ_m E_x^m = I_r ⟹ Σ_m F_x^m = D I_r^T D = D²；tr D² = Σλᵢ² = 1。∎

**注（转置约定）**：E ↦ E^T 是 POVM 可行集的自同构，最优值不受转置约定影响；机验 C1 偏差 ≤ 5.6e-17。

**推论（n 槽 ℤ_d 推广）**：同一归约对 x∈ℤ_dⁿ、消息 m∈ℤ_N、Bob 猜测 x_y∈ℤ_d 的 EA-RAC 逐字成立：F_x^m = D(E_x^m)^T D，S = (1/(n·dⁿ)) Σ_{x,y,m} tr[F_x^m M^{m,y}_{x_y}]，Σ_m F_x^m = ρ_B 与 x 无关。本文 d=2 全解即建于其上；d=4 见 §7。

## §2 转向系综算符归约（定理2，全证）

**定理2（转向归约）**：Schmidt 秩 ≤ r 的 EA-RAC 最优值等于

sup over 合法 F-分解 {F_x^m ≥ 0 : Σ_m F_x^m = ρ_B ∀x，ρ_B ≥ 0，tr ρ_B = 1，rank ρ_B ≤ r}，再对 Bob POVM 取 max 的 (1/8)Σ_{x,y,m} tr[F_x^m M^{m,y}_{x_y}]。

**可实现性引理**：任给合法 {F_x^m}（支撑于 rank-r ρ_B），取 supp(ρ_B) 上典范纯化 |ψ⟩=(ρ_B^{1/2}⊗I)Σᵢ|ii⟩，Alice 施 POVM A_x^m := (ρ_B^{-1/2} F_x^m ρ_B^{-1/2})^T（ρ_B^{-1/2} 为 supp 上伪逆），则 Alice 转向 Bob 的算符恰为 F_x^m。

**证（引理）**：A_x^m 由合同变换保半正定；Σ_m A_x^m = (ρ_B^{-1/2} ρ_B ρ_B^{-1/2})^T = I_supp，故为 POVM。转向恒等式 tr_A[(A⊗I)|ψ⟩⟨ψ|] = ρ_B^{1/2} A^T ρ_B^{1/2} = F_x^m。∎ 反向由定理1：任一策略给出合法 F。机验 C2 偏差 ≤ 1.8e-16。∎

**意义**：EA-RAC 优化从「态+双方测量」三元组降为纯算符分解优化 —— 无 SDP 求解器需求（cvxpy 不可得、pip DNS 封之环境下仍可行）。此即 DEBT-BOUND02-LEMMA-01 的嵌入落地：借范引理化为联邦内显式算符程序；其「常数重证」仍开放（债保持）。

## §3 二元猜测 Helstrom 闭式（定理3，全证）

**定理3**：二元猜测（x_y∈{0,1}）下 Bob 侧解析闭合。给定合法 F，

S(F) = 1/2 + Φ(F)/16，Φ(F) := Σ_{m=0,1} Σ_{y=0,1} ||Δ_y^m||₁，Δ_y^m := Σ_x (−1)^{x_y} F_x^m。

**证**：固定 (m,y)，令 H_v = Σ_{x:x_y=v} F_x^m。max_{二元 POVM (M₀,M₁)} Σ_v tr[H_v M_v] = tr H₁ + max_{0≤M≤I} tr[(H₀−H₁)M] = (tr(H₀+H₁) + ||H₀−H₁||₁)/2（Helstrom 精确式，非松弛）。各 (m,y) 独立可逐项取最优；Σ_m tr(H₀+H₁) = Σ_m Σ_x tr F_x^m = Σ_x tr ρ_B = 4，代入归一化 (1/8)·(1/2)Σ_{m,y}(·) 得 1/2 + Φ/16。机验 C3 恒等偏差 < 1e-10。∎

**推论**：S*_r = 1/2 + (1/16) · max_{合法 F, rank ρ_B ≤ r} Φ(F)。**问题完全化为一元算符范数泛函优化。**

## §4 d=2 紧致谱

### 4.1 r=1 [全证 · 一致性闸]

r=1：F_x^m = p(m|x) ∈ [0,1] 标量，ρ_B = 1；Φ = Σ_{m,y} |Σ_x (−1)^{x_y} p(m|x)| —— 恰为 BP-03（N=2）标量 LP。max Φ = 4 ⟹ S* = 3/4。机验 C4：全部 2⁴×2⁴ 确定性策略穷举最优 0.750000，与 BP-01/BP-03 完全一致 —— **嵌入 corollary 成立**（本框架在 r=1 精确退化为已证经典理论）。

### 4.2 r=2 下界 [全证构造 + 借证策略]

**仿射恒等式**：x_y = x₀ ⊕ (x₀⊕x₁)·y（y∈{0,1}）。

**保值归约 CHSH→RAC（全证）**：任给 CHSH 策略（胜率 p），定义 RAC 策略：Alice 以 x̂:=x₀⊕x₁ 为 CHSH 输入得输出 ã，发消息 m:=ã⊕x₀；Bob 以 ŷ:=y 为 CHSH 输入得输出 b̃，猜 b:=b̃⊕m。则

b ⊕ x_y = b̃ ⊕ ã ⊕ x₀ ⊕ x₀ ⊕ (x₀⊕x₁)y = (ã ⊕ b̃) ⊕ x̂ŷ，

逐点等值 ⟹ RAC 胜率 = CHSH 胜率 p（输入均匀性保持：x̂=x₀⊕x₁ 均匀，ŷ=y 均匀）。∎

取 Tsirelson 策略 [借证]：|Φ⁺⟩，Alice 测 Z/X，Bob 测 (Z±X)/√2，p = cos²(π/8) = (2+√2)/4。

**⟹ S*_{r=2} ≥ (2+√2)/4 = 0.8535533905932737**。机验 C5：显式构造直接二比特模拟偏差 5.6e-16；C6：归约式 Φ = 4√2 偏差 3e-15。

### 4.3 r≥2 上界 [借证]

Pawłowski–Żukowski, PRA 81, 042326 (2010) 给出 (2,1)-EARAC 上界（并称其上界同时限制 QRAC）；信息因果框架（Pawłowski 等, Nature 461, 1101 (2009)）对经典消息 EA-RAC 给出同值上界 cos²(π/8)。**本框架自足上界（Φ ≤ 4√2）未证 = DEBT-BOUND05-UB-01**。候选路线：Φ = max_{收缩 Q_y^m} Σ_{x,m,y} (−1)^{x_y} ⟨(E_x^m)^T ⊗ Q_y^m⟩_ψ 的 Tsirelson 型向量界 —— 障碍：Bob 算符以 Alice 结果 m 为指标，非标准 Bell 泛函，Tsirelson 定理不直接适用。
