# BOUND-PROOF-04 — 资源轴耦合定理:经典轴封闭 + 见证界 r=1 非紧致证书【全证】

## 一、Th A(经典轴封闭:共享随机性增益恒为零)【全证】

**命题**:经典 (2→1,ℤ_N) RAC 中,Alice-Bob 持**任意**(乃至无穷维)共享随机变量 λ,双方亦可各自局部随机,则

  S_max = (1+1/N)/2,且紧。

**证**:共享随机策略 = 确定性联合策略对 (f_λ,g_λ) 上的分布 q(λ);成功率对混合线性:E[S]=Σ_λ q(λ)·S(f_λ,g_λ) ≤ max_{f,g} S(f,g) = (1+1/N)/2(BP-03 主定理)。局部随机为特例(λ 退化)。紧性由 BP-03 步5 之确定性策略 f(x)=x₁、g(m,y)=m 直接继承(不需任何随机性)。∎

## 二、Th B(见证界 r=1 非紧致证书)【全证,前提=§〇】

Schmidt 秩 r=1 = 可分离共享态 = 经典共享关联;通信既为经典 ℤ₄ 符,则 r=1 协议类 ⊂ Th A 策略类 ⇒ **r=1 真实可达 max = 5/8 = 0.625(紧)**。而见证界公式取值 ½(1+√(1/8)) = 0.6767767 > 0.625。

**推论**:
1. 见证界于 r=1 **松 0.0517767**(非紧)。上界松不碍认证向——违反之仍证 Schmidt≥r+1,健全性无损;
2. 端点 r=8:公式=1.0,平凡紧;
3. **紧致谱开放**:r=2..7 之精确可达形 = 野问 qfa-18(本拍铸)。

## 三、判词律 v2(双基线纪律)

- 欲判「**超经典优势**」:基线=**紧界 0.625**(BP-03+Th A)。引松界值 0.6768 作"经典可达率"= 判词污染。
- 欲判「**Schmidt ≥ r+1**」:基线=见证公式 ½(1+√(r/8))(BP-02,[借-L2] 健全性承 PRL;r=1 之松不损认证向)。
- **禁**:把见证界在任一 r 的公式值表述为协议可达值,除非该 r 紧致性已证(当前仅 r=1 证非紧、r=8 平凡紧)。

## 四、Errata-BP03-01(链不诬,勘误续链)

BP-03 §判词射程 2「其差=共享经典关联(共享随机性)之优势」一句**归因错误**:Th A 证共享随机性于经典轴增益恒为零;0.625→0.6768 之差=**紧界与松界公式值之差**,非任何协议已实现之优势。三层阶梯修正表述:「紧界 0.625 ∥ 见证公式值轴 0.6768…1.0000(BP-02 借-L2,紧致谱开放)」。原件不涂改,本件即勘误位。
