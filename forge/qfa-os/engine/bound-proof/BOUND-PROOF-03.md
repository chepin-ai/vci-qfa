# BOUND-PROOF-03 — 经典 (2→1, ℤ_N) 随机存取码之精确界 S=(1+1/N)/2【全证】

承 BP-01（N=2 特例 3/4）·BP-02（Schmidt 秩界骨架）。本件把经典基线**从比特特例升为一般 ℤ_N 闭式定理**——融构第三件，无一借件，全证。

## 定理（精确界）

协议：Alice 持 x=(x₁,x₂)∈ℤ_N²（均匀 N² 元），经**一个 ℤ_N 符**经典消息 m=f(x)；Bob 得均匀问 y∈{1,2}，以 g(m,y) 答 x_y。则任何（含随机化）经典策略之平均成功率

**S ≤ (1+1/N)/2**，且界为紧——f(x)=x₁、g(m,y)=m 恰达之。

## 证（行列组合论证，qfa 原创于联邦内）

**步1（纤化归约）**：对每个消息 m，记纤 A_m=f⁻¹(m)⊆ℤ_N²，a_m=|A_m|，Σ_m a_m=N²。视 A_m 为 N×N 0/1 阵：行和 t_i=#{(x₁,x₂)∈A_m:x₁=i}，列和 u_j=#{(x₁,x₂)∈A_m:x₂=j}。固定 m 下，最优译码所获 = max_i t_i + max_j u_j（译码器择众数行/列）。

**步2（关键不等式）**：**max_i t_i + max_j u_j ≤ a_m + 1**。
证：设最大行含 r* 个 1（该行确有 r* 个 1），最大列含 c* 个 1；行与列之交至多 1 格，故 a_m ≥ r*+c*−1，即 r*+c* ≤ a_m+1。∎

**步3（求和）**：总成功对数 ≤ Σ_m (a_m+1) = N²+N。均匀先验 2N² 项，故

  S ≤ (N²+N)/(2N²) = **(1+1/N)/2**。

**步4（随机化不增界，Yao）**：同 BP-01 步二——随机策略为确定性混合，S_rand≤max_det。∎

**步5（紧性）**：f(x)=x₁、g(m,y)=m：每 m 之纤 A_m={(m,x₂)}，t_m=N、u≡1，恰获 N+1；总计 N(N+1)，S=(1+1/N)/2 达成。∎

**证毕。QED.**
